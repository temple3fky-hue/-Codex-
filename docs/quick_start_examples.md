# 示例：快速体验 Unsplash / Pexels / Pixabay

## 示例链接（可直接粘贴到主界面，每行一个）
- https://unsplash.com/photos/A-NVHPka9Rk
- https://www.pexels.com/photo/1108099/
- https://pixabay.com/photos/forest-fog-nature-trees-mystic-931706/

## 下载输出目录
- 默认下载目录：`downloads/`
- 可在 GUI 的“设置”页中修改“下载目录”。

## 导出文件位置
- CSV 默认导出：`exports/history.csv`
- Excel 默认导出：`exports/history.xlsx`

## GUI 操作步骤
1. 启动程序：`python main.py`
2. 在主界面 URL 输入框粘贴上面的示例链接（每行一个）
3. 点击“开始提取并下载”按钮
4. 在“下载进度”中查看进度与状态
5. 在“实时日志”中查看详细提示（含错误信息）
6. 点击“导出CSV”或“导出Excel”生成历史记录文件
